# .github

This is the `mabushi-lab` organization's special `.github` repository. It holds the public org profile and default community health files, which apply to every repo in the org that doesn't define its own.

- `profile/README.md`: the org landing page shown on github.com/mabushi-lab.
- `CODE_OF_CONDUCT.md`, `CONTRIBUTING.md`, `SECURITY.md`, `SUPPORT.md`: default community files.
- `.github/ISSUE_TEMPLATE/` (bug report, feature request, question) and `.github/PULL_REQUEST_TEMPLATE.md`: default issue forms and PR template.
- `.github/CODEOWNERS`: review ownership for this repository.
- `LICENSE`: MIT.
