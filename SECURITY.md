# Security Policy

## Reporting a vulnerability

Please report vulnerabilities privately. Don't open a public issue, pull request, or discussion.

1. Go to the **Security** tab of the affected repository.
2. Click **Report a vulnerability** (GitHub private vulnerability reporting).
3. Describe the issue, the affected version or commit, and steps to reproduce.

If the repository doesn't show that option, email [contact@braunf.com](mailto:contact@braunf.com) instead, with the repository name and the same details.

Several repositories here run on hardware that listens to or transmits on radio frequencies (NetworkSniffer, CrossWave). Reports about firmware flaws, unsafe defaults or misuse risks are in scope and welcome.

## What to expect

I'll acknowledge your report and keep you updated while I investigate. Please give me reasonable time to fix the issue before disclosing it publicly.

## Supported versions

Fixes go into the latest release, or the default branch where a repository has no releases.

## Scope

This policy covers repositories in the `mabushi-lab` organization unless a repo defines its own `SECURITY.md`.
