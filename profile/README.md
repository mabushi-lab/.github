# Mabushi Lab

*Research first. Hardware alongside.*

Mabushi Lab is where I publish independent research in cross-lingual NLP and LLM interpretability, next to open-source ESP32 hardware I build. Everything here is public and MIT licensed unless a repository says otherwise.

**Find me:** [research.braunf.com](https://research.braunf.com) for the research and hardware · [projects.braunf.com](https://projects.braunf.com) for my apps and tools · [braunf.com](https://braunf.com) for everything else.

## Research

My work sits between natural language processing, multilingual alignment and model interpretability: what small language models learn about language structure across very different languages, and whether the internal signals we use to evaluate models hold up under scrutiny.

## Hardware and tools

| Project | Description |
| --- | --- |
| [Pulsar](https://github.com/mabushi-lab/Pulsar) | A portfolio dashboard for the LilyGo T-Display-S3 (ESP32-S3): live public quotes, one-currency totals and a daily record of what the portfolio is worth. C++. |
| [NetworkSniffer](https://github.com/mabushi-lab/NetworkSniffer) | An ESP32 433 MHz RF analyzer with a live web dashboard served from the chip itself. No cloud, no app, no router. C++. |
| CrossWave | A pair of motion-sensing ESP32 devices with an MPU6050, 433 MHz RF, BLE provisioning, an OLED UI and WebSocket streaming. Repository coming soon. |
| [MarketLens](https://github.com/mabushi-lab/MarketLens) | A self-contained MATLAB project for learning MATLAB by building a time-series and portfolio toolbox, with a test suite. |
| [young-poor-busy](https://github.com/mabushi-lab/young-poor-busy) | ICPC Asia Regional 2001 (Hakodate) Problem F in C and Python, with two extensions. |
| [Resume](https://github.com/mabushi-lab/Resume) | A modular LaTeX resume collection with a Python GUI manager. |

The site behind all of this lives in [_Mabushi-Lab](https://github.com/mabushi-lab/_Mabushi-Lab) and is served at [research.braunf.com](https://research.braunf.com).
